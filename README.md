# Interstate Special Education Resource Allocation Analysis
**Course: IS477 Data Curation** | **Milestone 4: Full Pipeline & Analysis**

##  Project Overview
This project investigates the relationship between state-level economic wealth (Median Household Income) and resources allocated to special education—specifically focusing on students with hearing impairments.

## Reproducibility: Snakemake Pipeline
This repository features a fully automated data pipeline managed by **Snakemake**. To reproduce the entire analysis from raw data to final visualizations, ensure you have the dependencies installed and run:
